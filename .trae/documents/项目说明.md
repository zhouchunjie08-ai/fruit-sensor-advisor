# 果感知·智选助手 - 项目说明文档

> 农业机器人传感器实时选型与验证引擎

***

## 一、产品概述

### 1.1 项目背景

**果感知·智选助手** 是一款面向农业机器人研发领域的智能选型工具。我们发现，农业机器人在传感器选型过程中存在以下痛点：

* 传感器产品海量，筛选困难

* 网上信息繁杂，难以判断可靠性

* 咨询厂商只能获得单一视角信息

* 缺乏同行案例参考

通过 AI 技术，我们希望让传感器选型从"2周"缩短到"2分钟"。

### 1.2 核心理念

**我们不是在"给答案"，而是"帮用户自己做决策"。**

与传统的推荐系统不同，我们强调：

* **透明**：展示决策推理过程，用户可质疑

* **自主**：提供自由探索模式，用户可自行筛选对比

* **可验证**：开放验证功能，用户可查证

***

## 二、功能介绍

### 2.1 智能推荐 + 决策树展示

用户输入自然语言需求（如"草莓采摘机器人需要判断成熟度"），系统返回推荐方案。

**核心亮点**：在推荐结果之前，展示"选型推理过程"——让用户看到 AI 是如何分解需求、筛选候选产品、做出最终推荐的。

> 📷 **截图位置**：智能推荐 + 决策树展示界面

!\[智能推荐界面示意]\(screenshot-1.png null)

**功能说明**：

* 需求分解：颜色检测 → 视觉传感器

* 候选产品展示：华测 M620（农业场景验证，证据A级）、某竞品（未验证，证据B级）

* 选择原因标注

### 2.2 自由探索模式

部分用户不想"等推荐"，而想"自己挑"。点击搜索框旁边的"自由探索"按钮，进入多维度筛选模式。

> 📷 **截图位置**：自由探索模式界面

!\[自由探索界面示意]\(screenshot-2.png null)

**筛选维度**：

* 传感器类型（可多选）

* 应用场景

* 预算范围

* 关键要求（抗冲击、防水IP67、宽温等）

### 2.3 产品对比

自由探索模式下，用户可选择 2-3 个产品加入对比，系统生成对比表格。

> 📷 **截图位置**：产品对比表格

!\[对比表格示意]\(screenshot-3.png null)

**对比维度**：

* 型号、类型、价格、等级、供应商

### 2.4 验证功能

每个推荐方案旁边提供"验证"按钮，点击后搜索该组合的实际应用案例。

> 📷 **截图位置**：验证结果展示

!\[验证功能示意]\(screenshot-4.png null)

**验证内容**：

* 实际应用案例

* 中标公告

* 用户可自行点击来源链接查证

### 2.5 询价功能

选型后如何采购？提供一键生成询价邮件功能。

> 📷 **截图位置**：询价邮件模板

!\[询价功能示意]\(screenshot-5.png null)

**功能**：

* 自动填充产品型号、供应商信息

* 包含批量采购价、样片申请、农业场景案例询问

* 一键复制到剪贴板

### 2.6 用户反馈机制

每个推荐方案下方提供"有用/不合适"反馈按钮。

> 📷 **截图位置**：用户反馈按钮

!\[反馈功能示意]\(screenshot-6.png null)

**价值**：

* 收集真实用户反馈

* 持续优化推荐算法

* 展示系统可进化性

## 三、技术架构

### 3.1 技术栈

| 层级    | 技术选型               | 说明             |
| ----- | ------------------ | -------------- |
| 前端    | Vue 3 + CDN        | 单 HTML 文件，无需构建 |
| 后端    | Python Flask       | 轻量级 Web 框架     |
| 数据存储  | JSON 文件            | 本地知识库          |
| AI 能力 | DeepSeek API       | 智能信息提取、结构化输出   |
| 搜索能力  | Bing API / DDG API | 实时网络检索         |

### 3.2 数据结构

**传感器数据**：

* 型号、类型、供应商、等级

* 关键参数、价格区间

* 供应商联系方式

* 证据等级（A/B/C）

**场景方案**：

* 适用场景标签

* 推荐传感器组合

* 选型理由

* 测试建议

* 典型客户案例

## 七、应用场景

### 7.1 草莓采摘机器人

* 成熟度检测（颜色+硬度）

* 推荐方案：华测 M620 + 天羿 EAM1011

### 7.2 番茄采摘机器人

* 目标识别 + 避障

* 推荐方案：速腾聚创 RS-LiDAR-M1 + 北醒光子 TF02-Pro

### 7.3 农业无人机

* 病虫害监测 + 地形测绘

* 推荐方案：Luxonis OAK-D + 禾赛科技 XT16

### 7.4 果园自主导航

* SLAM 建图 + 避障

* 推荐方案：速腾聚创 RS-LiDAR-M1 + 博世 BMI088

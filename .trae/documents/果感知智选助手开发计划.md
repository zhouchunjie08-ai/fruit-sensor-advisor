# 果感知·智选助手 - 3小时极速开发计划

## 一、项目目标（3小时）

**核心目标**: 交付一个可运行的传感器选型Web应用，包含基本功能和演示数据。

**交付物**:
- 可运行的Web应用（前端+后端）
- 传感器选型推荐功能（本地知识库）
- 简洁的说明文档
- 部署说明

---

## 二、技术栈（精简版）

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| 前端 | 单HTML文件 + Vue 3 CDN | 零依赖，直接浏览器打开 |
| 后端 | Flask (Python) | 简单易上手，单文件可运行 |
| 数据 | JSON 文件 | 无需数据库，快速开发 |
| 部署 | PythonAnywhere / Render | 免费Python主机 |

---

## 三、开发步骤（3小时 = 180分钟）

### 第1阶段：基础搭建（0-30分钟）

| 任务 | 时长 | 产出 |
|------|------|------|
| 创建项目目录结构 | 5分钟 | 目录结构 |
| 编写传感器数据JSON | 15分钟 | sensors.json（含5-10个传感器） |
| 编写组合方案JSON | 10分钟 | scenarios.json（含3-5个场景） |

### 第2阶段：后端开发（30-75分钟）

| 任务 | 时长 | 产出 |
|------|------|------|
| 搭建Flask服务 | 15分钟 | app.py 可运行 |
| 实现传感器查询API | 15分钟 | /api/sensors 接口 |
| 实现场景推荐API | 15分钟 | /api/recommend 接口 |

### 第3阶段：前端开发（75-140分钟）

| 任务 | 时长 | 产出 |
|------|------|------|
| 编写HTML页面结构 | 15分钟 | index.html |
| 实现Vue组件（输入+结果展示） | 30分钟 | 完整的交互界面 |
| 样式美化 | 20分钟 | 响应式设计，良好用户体验 |

### 第4阶段：测试与部署（140-180分钟）

| 任务 | 时长 | 产出 |
|------|------|------|
| 本地测试 | 15分钟 | 确保功能正常 |
| 编写README文档 | 10分钟 | 部署说明 |
| 准备部署 | 15分钟 | 确保可部署 |

## 七、快速启动

```bash
# 1. 安装依赖
pip install flask flask-cors

# 2. 启动后端
python backend/app.py

# 3. 打开前端
# 直接用浏览器打开 frontend/index.html
```

## 八、关键原则

1. **快速可用**: 3小时内必须产出可运行结果
2. **数据驱动**: 用丰富的示例数据弥补功能简化
3. **清晰展示**: 界面简洁，重点突出推荐方案
4. **可扩展**: 预留实时检索接口，后续可扩展
